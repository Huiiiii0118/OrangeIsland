## 首发

- **Orange island 1.0.0**：首个正式版本，把通知、音乐、系统读数、剪贴板与格式转换收进屏幕顶部的一块灵动岛。
- 开箱即用：单个自包含可执行文件，无需安装 .NET 运行时。

## 功能

### 灵动岛面板

- 收起时是刘海、胶囊或指示条，鼠标移入即展开，移开后自动收回；全部页面均可锁定展开。
- 每块显示器各有一块小岛，位置独立记忆；面板中心跟随屏幕与两侧需求自动摆放。
- 通知、音乐、系统监控、剪贴板与格式转换五个页面自由排序、调整大小、单独开关。
- 支持主题模板与强调色，深浅色跟随系统。

### 通知

- 监听固定的 21 个聊天与邮件程序，白名单之外的通知一律不显示。
- 胶囊显示未读条数，点击直接拉起对应软件并标记已读。
- 把该程序切到前台（无论是否通过通知打开）也会自动结束提醒。

### 音乐

- 接管系统媒体会话：封面、律动条、歌词与播放控制，含进度条拖动。
- 展开页左侧提供静音按钮与系统主音量条，音量随外部调节实时同步。
- 封面兜底：视频标题含 BV 号时从 B 站取封面，歌曲通过 iTunes Search API 查找。

### 系统监控

- CPU、内存、磁盘、网速、温度、功耗与帧率实时读数。
- 帧率经 ETW 采集，兼容启动器与游戏本体不同名的情况（如梦幻西游），按真正绘制的进程计数。

### 剪贴板

- 文字、图片与文件的历史记录，可搜索、可收藏。

### 格式转换

- 图片、文档、表格、文本、音视频与 PDF 互相转换。
- 全部在本机完成，使用内置的 FFmpeg，文件不出电脑。

### 更新

- 应用内检查 GitHub Releases 新版本，下载后由更新助手自替换完成升级。
- 更新包多段并行下载、断点续传；检查接口被限流时自动降级，不依赖代理。

## 其他

- 采用 [MIT License](LICENSE) 开源；发布包为单个自包含 `OrangeIsland-X.Y.Z-windows-x64.exe`，无需安装 .NET 运行时。

## First release

- **Orange island 1.0.0**: the first public release, bringing notifications, music, system readings, clipboard history and file conversion into one island at the top of the screen.
- Ready to run: a single self-contained executable, with no .NET runtime to install.

## Features

### The island

- Collapses to a notch, capsule or bar; expands on hover, folds away when the pointer leaves. Any page can stay pinned open.
- One island per display, each remembering its own spot; the panel centers itself between what both sides need.
- Five pages — notifications, music, system monitor, clipboard and conversion — freely reordered, resized and switched on or off.
- Theme templates and accent colors, following the system light or dark mode.

### Notifications

- Watches a fixed whitelist of 21 chat and mail programs; anything outside it is never shown.
- The capsule shows the unread count; clicking it opens the program and marks its notices read.
- Bringing that program to the foreground — through the notice or not — ends its reminders too.

### Music

- Takes over the system media session: cover, equalizer bars, lyrics and transport controls, with a draggable progress bar.
- A mute toggle and a system volume bar sit on the left of the expanded page, following external volume changes live.
- Cover fallback: video titles with a BV id fetch their poster from Bilibili; songs are looked up through the iTunes Search API.

### System monitor

- Live readings for CPU, memory, disk, network speed, temperature, power and frame rate.
- Frames come from ETW and handle launchers whose game process has a different name (梦幻西游 among them), counting the process that actually draws.

### Clipboard

- Searchable history of text, images and files, with favorites.

### Conversion

- Converts between pictures, documents, spreadsheets, text, audio, video and PDF.
- Everything happens locally with the bundled FFmpeg; files never leave the machine.

### Updates

- The app checks GitHub Releases for a new version; an update helper swaps the executable in place after download.
- Update packages download in parallel segments with resume; when the check API is rate-limited it falls back automatically, with no proxy required.

## Other

- Open source under the [MIT License](LICENSE). The release is a single self-contained `OrangeIsland-X.Y.Z-windows-x64.exe`; no .NET runtime is needed.
