## 首发

- **Orange island 1.0.0**：首个正式版本，把通知、音乐、系统读数、剪贴板与格式转换收进屏幕顶部的一块灵动岛。
- 开箱即用：单个自包含可执行文件，无需安装 .NET 运行时。

## 功能

- **灵动岛面板**：刘海 / 胶囊 / 指示条三种收起样式，鼠标移入展开；通知、音乐、系统监控、剪贴板与格式转换五个页面可自由排序、调整大小与开关，每个显示器各有一块小岛。
- **通知**：监听固定的 21 个聊天与邮件程序；点击胶囊拉起对应软件并标记已读，把该程序切到前台也会自动结束提醒。白名单之外的通知一律不显示。
- **音乐**：封面、律动条、歌词与播放控制；展开页左侧提供静音按钮与音量条，可调节系统主音量并跟随外部音量变化。缺少封面的视频标题会尝试按 BV 号从 B 站取封面，歌曲则通过 iTunes Search API 查找。
- **系统监控**：CPU、内存、磁盘、网速、温度、功耗与帧率；帧率识别兼容「启动器与游戏本体不同名」的情况（如梦幻西游），不再显示 0 FPS。
- **剪贴板与格式转换**：文字、图片、文件历史可搜索收藏；图片、文档、表格、文本、音视频与 PDF 全部在本机转换，使用内置的 FFmpeg。

## 改进

- **更新页面新增「稍后」**：点击后本次运行不再弹出提示，下次启动软件才再次提醒；「跳过此版本」仍然长期生效。
- **无代理下载提速**：更新包改为 6 段并行 Range 下载、4 路并发，每段独立断点续传；每段重试 3 次，`github.com` 直链失败时自动改走 API 资产端点，并保留 30 秒无数据超时重连。
- **更新检查限流降级**：GitHub API 返回 403/429 时改走网页版 latest 重定向解析版本，不占用 API 配额。
- **界面细节**：通知胶囊去掉灰色底纹并统一文字基线；音乐页加宽到 660，系统监控与音乐页底部随面板高度增加留白，展开 / 收起按钮不再压住数据。

## 其他

- 采用 [MIT License](LICENSE) 开源；发布包为单个自包含 `OrangeIsland-X.Y.Z-windows-x64.exe`，无需安装 .NET 运行时。

## First release

- **Orange island 1.0.0**: the first public release, bringing notifications, music, system readings, clipboard history and file conversion into one island at the top of the screen.
- Ready to run: a single self-contained executable, with no .NET runtime to install.

## Features

- **The island**: notch, capsule or bar when collapsed, a panel on hover. Notifications, music, system monitor, clipboard and conversion pages can be reordered, resized and switched off; one island per display.
- **Notifications**: a fixed whitelist of 21 chat and mail programs. Clicking the capsule opens the program and marks its notices read; simply bringing that program to the foreground does the same. Anything outside the whitelist is ignored.
- **Music**: cover, equalizer bars, lyrics and transport controls, with a mute toggle and a system volume bar on the left of the expanded page that follows external volume changes. Video titles without a cover fetch a poster from Bilibili when they contain a BV id; songs are looked up through the iTunes Search API.
- **System monitor**: CPU, memory, disk, network, temperature, power and frame rate. Frame-rate detection now handles launchers whose game process has a different name (for example 梦幻西游) instead of reporting 0 FPS.
- **Clipboard and conversion**: searchable text, image and file history; pictures, documents, spreadsheets, text, audio, video and PDF convert locally with the bundled FFmpeg.

## Improved

- **"Later" on the update page**: dismissing it silences the prompt for this run only; it returns on the next start. "Skip this version" still persists.
- **Faster direct downloads**: updates arrive as six parallel Range segments, four in flight at a time, each resuming independently. Every address is retried three times, a failed github.com link falls back to the API asset endpoint, and a 30-second stall reconnects.
- **Rate-limit fallback for update checks**: when the GitHub API answers 403/429, the version comes from the web "latest" redirect instead, which spends no API quota.
- **Interface details**: the notification capsule lost its grey fill and shares one text baseline; the music page widened to 660, and the system-monitor and music pages add bottom space with panel height so the expand / collapse buttons no longer cover the last row.

## Other

- Open source under the [MIT License](LICENSE). The release is a single self-contained `OrangeIsland-X.Y.Z-windows-x64.exe`; no .NET runtime is needed.
