## 改进

### 通知

- 通知页改为左右两栏：左侧完整显示选中的通知，右侧保留列表，查看内容不再弹出新窗口。
- 聊天与邮件通知点一下就在左侧展开全文，不会自动标记为已读，列表滚动位置保持不变。
- 邮件现在连同正文一起显示：读取时解码 MIME 正文、自动识别文字编码并去掉网页标签。
- 正文里的验证码以绿色高亮，点一下即可复制。
- 点邮件胶囊会展开小岛并定位到那封邮件；通知页没打开时则直接打开邮件程序。
- 通知行更高、字号更大，一屏约 3 条；工具栏上的「检查邮箱」按钮已移除。

### 邮箱

- 授权码改用明确的「保存」按钮：填好后点保存，输入框内会显示「已保存，输入新授权码可更换」，一眼就能确认；留空再保存不会清掉原有授权码。
- 点「检查邮箱」后会弹出连接结果，成功显示新邮件数，失败说明原因，不用再猜有没有连上。

### 外观默认

- 收起样式默认改为胶囊。
- 胶囊显示内容默认全开：音乐、律动条、时钟与系统监控。
- 展开面板的页面默认全部显示：通知、音乐、系统监控、剪贴板与格式转换；「恢复默认」也会把这些页面一并打开。

## Improvements

### Notifications

- The page splits into two panes: the selected notice in full on the left, the list on the right — no more pop-up window.
- Every notice (chat or mail) opens in the left pane on click, without being marked read, and the list keeps its scroll position.
- Mails now include their body: MIME parts are decoded, the charset is detected and HTML tags are stripped.
- One-time codes are highlighted in green in the detail and copied with a click.
- Clicking a mail capsule expands the island and selects that mail; when the notifications page is closed it falls back to opening the mail app.
- Taller rows and larger text fit about three notices per screen; the "Check mail" toolbar button is removed.

### Mail

- The app password now has an explicit Save button: once saved, the field reads "Saved — type a new code to replace it", so it is clear the code was stored. Saving while the field is empty keeps the existing code.
- "Check mail" now shows a result dialog — the number of new mails on success, or the reason on failure — so the connection outcome is never in doubt.

### Appearance defaults

- The collapsed style now defaults to the capsule.
- All capsule items are on by default: music, equalizer bars, clock and system monitor.
- All expanded-panel pages are shown by default: notifications, music, system monitor, clipboard and conversion; "Restore defaults" turns them all back on too.
