## 新增

- **展开栏音乐板块音量调节**：播控行新增静音按钮与音量条，拖动或点击即可调节系统主音量；滑条约每 250 毫秒跟随系统音量（键盘音量键、音量混合器）刷新，聚焦后可用方向键步进 5%、PageUp/Down 步进 25%。窄面板空间不足时自动只保留静音按钮。
- **打开聊天软件即已读**：不必点击胶囊，只要把通知对应的程序切到前台（任务栏、Alt+Tab、Dock 均可），该程序的未读通知即自动标记已读、提醒消失；通知条目仍保留在列表中。邮件类通知在打开任意邮件客户端时同样结束提醒。
- **全聊天软件识别**：前台已读覆盖全部被监听的聊天与办公程序，包括微信、QQ、TIM、企业微信、钉钉、飞书、Teams、Slack、Discord、Telegram、WhatsApp、LINE、Skype 等，也支持商店版 / UWP 应用（窗口由系统外壳托管）。通知产生与前台识别共用同一套判定，不再出现「提醒了、打开软件却不清」。

## 改进

- **更新下载更抗网络抖动**：改为断点续传（失败保留已下载部分，下次从断点接着下），每个地址自动重试 3 次；`github.com` 直链不可用时自动改走 API 资产端点，同一代理节点上两条路由表现分裂时不再让 117 MB 的包从头重来。
- **更新检查限流降级**：GitHub API 返回 403/429（匿名配额耗尽）时，改走网页版 latest 重定向解析版本，不占用 API 配额；此路径下更新说明为空。
- **音乐页更舒展**：音乐页最小/默认宽度由 440 提升到 660，静音按钮与音量条同处播控行左侧（按钮在前、滑条在后），播放三连按钮间距收紧，音量区不再局促。
- **展开 / 收起按钮不再压住数据**：「系统监控」与「正在播放的音乐」两页的底部留白按面板高度渐变增加，右下角按钮与最后一行数据之间留出间隙；矮面板不额外占用空间。
- **通知胶囊更干净**：去掉「微信 通知26条」外层的灰色底纹，内容直接落在黑色胶囊上；发件人与条数合并为同一行文字、共享同一基线，消除字体错落感。

## 其他

- 音乐页默认宽度调整为 660；旧配置文件中较小的宽度会在加载时自动提升，无需手动改设置。

## New

- **Volume control in the music page**: the expanded music page now has a mute toggle and a volume bar in the transport row. Drag or click to set the system master volume; the bar follows external changes (volume keys, the mixer) about four times a second, and arrow keys step 5% / PageUp-Down 25% while focused. A narrow panel keeps only the mute toggle.
- **Opening a chat app marks it read**: bringing the program a notice came from to the front — taskbar, Alt+Tab or a dock — ends its reminder without clicking the capsule. Notices stay in the list; only their unread state ends. Mail notices are answered by opening any mail client.
- **Every chat program recognised**: the foreground read now covers all watched chat and office programs, including WeChat, QQ, TIM, WeCom, DingTalk, Feishu, Teams, Slack, Discord, Telegram, WhatsApp, LINE and Skype, as well as Store / UWP builds whose windows the shell owns. The notification watch and the foreground read share one recognition path, so a program can no longer announce a message and then fail to be recognised when opened.

## Improved

- **Update downloads survive an unstable network**: downloads resume from a partial file after a dropped connection, retry each address three times with a short backoff, and fall back to the API asset endpoint when the github.com redirect is unreachable. A shared proxy node no longer forces the 117 MB package to restart from zero.
- **Rate-limit fallback for update checks**: when the GitHub API answers 403/429 (anonymous quota exhausted), the version is resolved from the web "latest" redirect instead, which costs no API quota; release notes are empty on that path.
- **Roomier music page**: the page's minimum/default width goes from 440 to 660, the mute toggle and the volume bar sit together on the left of the transport row (toggle first), and the transport spacing is tightened so the volume group is no longer cramped.
- **Space for the expand / collapse buttons**: the bottom margin of the system-monitor and now-playing pages grows with panel height, keeping the buttons in the lower-right clear of the last row of readings. Short panels keep their room.
- **Cleaner notification capsule**: the grey fill behind the sender and unread count is gone, and both now share one text line and one baseline, removing the uneven type.

## Other

- The music page's default width is now 660; a smaller width in an existing settings file is raised on load.
